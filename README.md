# mzQC clinical Lipidomics Use Case

This repository demonstrates a workflow for exporting quality control (QC) metrics from an MRMhub-based targeted lipidomics workflow into the mzQC format.

## Workflow origin

The currently used lipidomics processing workflow is adapted from the official MRMhub tutorial developed by Bo Burla, Gui Shou Teo, and Hyungwon Choi:

https://slinghub.github.io/MRMhub/articles/T01_targetlipidomics_workflow.html

The example dataset `data/long.csv` and `data/metadata-template.xlsx` currently used in this repository is also obtained from the MRMhub project:
[MRMhub_version_20260315](https://github.com/SLINGhub/MRMhub/releases)

Burla B, Teo G, Choi H (2026). *mrmhub: Small Molecule Mass Spectrometry Data Processing, Quality Control, and Reporting*. R package version 0.9.2.
https://github.com/SLINGhub/MRMhub

This repository extends the original workflow by generating mzQC-compatible quality control outputs using the `rmzqc` R package:

https://github.com/MS-Quality-hub/rmzqc

## Repository structure

* `data/` — input datasets and metadata
* `script/` — workflow script
* `output/` — generated workflow reports and mzQC file


## Notes

* The workflow currently uses the processed `long.csv` dataset generated by the MRMhub INTEGRATOR module.
* All output files are written to the `output/` directory.
